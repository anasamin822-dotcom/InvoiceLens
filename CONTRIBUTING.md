# Contributing to Invoice Review

Thank you for your interest in contributing!

## Development Setup

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Run tests:
   ```bash
   npm run test
   ```
5. Build for production:
   ```bash
   npm run build
   ```

## Code Guidelines
- Strict TypeScript mode enabled; no `any`.
- Keep components modular, accessible, and clean.
- Unit test validators, coordinate conversion, and reducer logic in `tests/`.
- Ensure clean code standards (ESLint / Oxlint).
